# Research notice — P2 EN→TL nanochat

This repository holds one-seed preregistered research checkpoints (AsPredicted #306935). It is **not** a production language model, chat system, or safety-certified artifact.

The complete A0/A1/A2/A3 weight bundle, matching `meta_*.json`, and P2 English tokenizer files are included. Optimizer states are not.

Do not confuse these files with P1.1 (`pageman/nanochat-filipino-p1-fixed-d20-3x`). P2 children were **not** initialized from the P1.1 Hub checkpoint.

Raw WikiText-103 test text, P1.1 protected holdouts, and secrets are not released here.
