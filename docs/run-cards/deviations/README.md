# Run-card deviations

Write a dated card here **before** executing any change that touches a frozen confirmatory element or a gate invariant. A deviation cannot make a departed run confirmatory after the fact; it only classifies the impact.

Template fields:

- Date (UTC)
- Frozen statement affected
- Change
- Why unavoidable
- Expected methodological impact
- Confirmatory eligibility retained? (yes/no + justification)
- How the result will be labeled
